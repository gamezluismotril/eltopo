\# ELTOPO



Sistema de análisis de datos para day trading.



\*\*IMPORTANTE:\*\* Esta aplicación ofrece análisis de datos, no asesoramiento financiero. Todas las decisiones operativas son responsabilidad del usuario.



\---



\## Qué es ELTOPO



Sistema que analiza \*\*2.336 acciones\*\* de NYSE, NASDAQ y AMEX y genera diariamente una lista de "Valores Destacados" separada en LONG y SHORT, con un score técnico de 0 a 100 y colores semáforo.



\*\*Filosofía:\*\* análisis de datos puro, sin recomendaciones. El usuario interpreta y decide.
